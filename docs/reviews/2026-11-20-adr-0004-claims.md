# Review record: the factual claims behind ADR 0004

ADR 0004 (the architecture) rests on facts taken from the research notes in
`docs/research/` and from its design work: version floors, API behaviour,
protocol rules. This record lists each of those facts as one claim, with the
source it was checked against and the verdict. The ADR cites a claim by its
id.

## Method

- **Gathering (2026-11-19).** Claude Sonnet 5.5 gatherers, one per area
  below. Each claim was written as one
  atomic fact in our own words, with its primary source, the date it was
  read and how it is known. Primary sources only: specifications, RFCs,
  Internet-Drafts, vendor and OS documentation, man pages, SDK headers,
  release notes and published AFS documents. Under ADR 0001, no source code,
  interface-definition file or header of OpenAFS, AuriStor or the Linux
  kernel's AF_RXRPC or kafs was read.
- **Verdicts (2026-11-19).** GLM 5.3, with web access, re-read each source
  and gave each claim a verdict. It also listed claims the gatherers missed
  in the notes; those have ids with an `M` (for example `PLT-M04`).
- **Controller check (2026-11-19).** The controller (Claude Opus 5.5) re-read
  the cited source for every claim GLM did not confirm, and for every
  confirmed claim that a design decision rests on (version floors, FUSE,
  FSKit, SMB, Cloud Files, rxgk and AFS facts): 158 claims. It agreed with GLM on
  144, disagreed on 12 and could not reach the source for 2. Where it
  disagreed, the table gives its verdict and GLM's. Rows it checked say
  "(controller)" in the last column.
- A few facts about Apple's NFS and SMB clients were checked against Apple's
  published client source. No documentation states them, so they carry no
  source link.
- The two Windows verdict runs both numbered their missed claims from
  `WIN-M01`. The second run's `WIN-M01` to `WIN-M16` appear here as
  `WIN-M41` to `WIN-M56`.

## Labels

- **CONFIRMED:** the source states the claim.
- **AMEND:** the claim is partly right. The ADR uses the corrected form.
- **REFUTED:** the source contradicts the claim. None was found.
- **UNVERIFIED:** no reachable public source settles the claim. The ADR names
  any such claim it rests on as an assumption, with what would settle it.
- **UNVERIFIED-PRIVATE:** the claim rests on a measurement whose record is
  not public. The ADR does not cite it.

## Summary

684 claims: 524 CONFIRMED, 31 AMEND, 0 REFUTED, 20 UNVERIFIED and 109 UNVERIFIED-PRIVATE.

Where the controller disagreed with GLM:

- Now CONFIRMED: `PLT-060` (the cited man page is gone, but `mount.fuse3(8)`
  states the rule), `DES-013`, `DES-058` (from maintainers' list posts, not
  a specification), `DES-074`, `DRV-081` (the scanned letter is readable),
  `MAC-M25`, `MAC-M27` and `WIN-193` (with a second Microsoft source).
- Now AMEND: `DES-076` (both RPCs exist; the order of use is the design's
  assumption), `MAC-M28`, `WIN-182` (it covers programs that use the Windows
  resolver) and `MAC-M23` (it stays AMEND, but the open question is settled).
- Not reached: `DES-007` (the Red Hat chapter refused the request; a Red Hat
  article of September 2025 still calls encrypted DNS on RHEL 10 a
  Technology Preview, against GLM's reading) and `WIN-098`.
