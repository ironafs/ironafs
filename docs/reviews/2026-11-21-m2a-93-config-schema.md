# Review record: the configuration schema (issue #93, part (b))

## The change

Class S. Issue #93, part (b).

- `docs/specs/config-schema.md` (status draft): M2a's configuration keys
  with their types, ranges, defaults, layers and reload or restart
  behaviour; the unknown-key and unknown-value rules for local files and
  for policy; the descriptor walk that decides a source's trust, the same
  for local files and policy; one result for every source state;
  layering, with policy locking its keys and a policy floor never lowered
  by a local value; the schema's versioning; and the named interfaces for
  parts (c) to (f). Q1 to Q12 decided by the controller.
- Built on `docs/specs/config-syntax.md` (part (a)). No code.
