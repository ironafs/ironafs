# Review of the Linux ABI header list (#159)

Class S. The [#118 review](2026-11-21-m2a-57-os-part-a.md) recorded
that removing an item from the declaration files and the editable copy
could skip its assertion if the copy also stopped naming the header.
The owner accepted the exact amendment to ADR 0005 point 2 on
2026-11-25 before implementation. Patch SHA-256
`2dde31ef2d3df5c77c5e005597a6cd454ba019e5ddd79b7b811a51d8d96c2e31`,
base `cd5aef93989f79e216eddedaf8816772c92d4240`. Applying the approved
patch independently yielded the same ADR text as the implementation.

## Implementation evidence

- EXECUTED on arm64 glibc 2.41 with GCC 14.2 and Rust 1.100.0.
  The clean old and new `check-abi` runs proved all eight rows. The clean
  `check-os` output on the same six installed triples was identical,
  with 24 ADR rows and 58 sites in 81 files.
- EXECUTED in the same venue. Move `SYS_getrandom` from its declaration
  module to the row's top-level code and remove its mirrored C fact.
  While `sys/syscall.h` stays, both checkers report the missing declaration
  of the macro. Removing the mirror's direct header also lets the old
  checker pass row 8, still proving the `syscall` type and three errno
  constants. The new `check-abi` and `check-os` fail with a row 8 header
  diagnostic. File syscall traces in fresh target directories confirmed
  rejection before creation of any generated C proof input.
- EXECUTED on arm64 musl with GCC 14.2 and Rust 1.100.0. The clean run
  proved the seven implemented foreign rows and reported row 14
  withheld. Omitting `sys/uio.h` from the mirror failed in the shared
  inventory. A fixture `sys/socket.h` forwarded to the native header
  and supplied `SCM_PIDFD` there. The qualified probe then refused
  withholding. All three qualified inputs included `sys/socket.h`
  followed by `sys/uio.h` and kept `_GNU_SOURCE`.
- EXECUTED. The new inventory regression failed on the base and passed
  after implementation. Native GNU and musl tests passed for direct
  ordered includes, including the macro scan and assertion define
  difference. The Darwin test passed for row 11's Linux scope.
  The local `cargo xtask check` passed 1,001 nextest tests, doctests,
  REUSE, cargo-deny and the existing checks. Clippy passed with warnings
  denied for arm64 GNU and musl Linux, macOS and Windows.

  the cell. Tests isolate invalid input on each side, two invalid
  inputs, an ineligible matched list, and mispaired rows.
