# Review of the Linux FUSE mount binding (#57)

Class S. The owner approved the row 15 direct-header amendment before
implementation. The amendment names `sys/mount.h`. The row and sheet
are in [ADR 0005](../adr/0005-ironafs-os.md). The caller still owns
mountpoint selection and policy under
[ADR 0004 L7](../adr/0004-architecture-2-os-layers.md).

## Reviews and convergence

| Seat | First implementation at `896fd3d` | First fix to `dd61175` | Second fix to `24f608a` |
|---|---|---|---|
| GLM 5.4 High | PASS, zero findings after continuation | PASS, zero findings | PASS, zero findings |
| Gemini Carbon High, independent | FAIL, two blockers, one major, one minor | FAIL, one blocker, one major, one minor | PASS, zero findings |
| Gemini Carbon Medium, security | FAIL, one major, one minor | PASS, zero findings | PASS, zero findings |

Before code, GLM 5.4 Max, Gemini Carbon High and Gemini Carbon Medium
passed the exact header amendment. The first implementation review
found missing native refusals, overly broad test privileges, mount
option gaps and missing legacy x86-64 runtime evidence. The first
fix added the native refusals and a non-owner request with restricted
capabilities. The second fix made mount owner IDs distinct and checked
the option sets and unsigned ID encoding. The smaller ID introduced
by the first fix left the high-bit range untested. The second fix
added that coverage. The final scoped reviews found no new findings.

## Evidence

- EXECUTED on ARM64. All five mount tests at `24f608a` passed on
  current GNU glibc, musl and glibc 2.28. The tests covered a real FUSE
  mount and non-owner GETATTR, mounted option and owner readback, six
  kernel argument refusals, NUL rejection and both missing-privilege
  cases. Each privileged case ran in its own private mount and PID
  namespaces under a deadline.
- EXECUTED on ARM64 glibc 2.28. The exact nextest selection for the
  denied libc mount call passed inside a restricted container without
  `CAP_SYS_ADMIN` or `/dev/fuse`. The per-target ABI check passed
  against the GNU, musl and legacy GNU headers used in the ARM64 runs.
- EXECUTED. Formatting and workspace Clippy with warnings denied
  passed across all seven supported triples. The three Miri stand-in
  tests passed on both GNU Linux triples, including the exact flags,
  option bytes and high unsigned IDs.
- MISSING. The native x86-64 mount success and kernel refusal cases
  on glibc 2.28 need a FUSE-capable venue. Current x86-64 GNU and musl
  kernel tests await hosted CI. The conditional glibc 2.17 artifact
  has its own qualification gate.

The binding reuses the OS crate's named ABI site and Miri stand-in
pattern. The diff keeps the approved C declaration, options and flags
together. The runtime test proves Linux's observed options and an
actual request through the mounted filesystem.
