# Review record: `docs/specs/` and the XDR profile

## The change

Class S. Issue #42 (plan id M2a-01).

- `docs/specs/README.md`: what a specification is; kinds, naming,
  status and freezing; how a specification cites ADR decisions; the
  sources and provenance rules under ADR 0001 and ADR 0004 N31; labelling
  claims; the register of editions (RFC 4506 and the pinned Rust `Vec`
  documentation); test vectors, fuzz targets and published conformance
  corpora; the least review class per kind; the index.
- `docs/specs/template.md`: the sections every specification has.
- `docs/specs/xdr.md`: the XDR profile IronAFS uses, from RFC 4506: the
  closed set of types, caps in bytes on every variable-length item and
  message, a memory budget counted by the decoder and proved by the
  generator, limits on inline size and nesting depth, strict decoding
  with per-field sourced tolerance, the canonical encoder, a closed error
  set that carries no input values, and its tests.
- `docs/README.md`: an index row for `docs/specs/`.
- **Written by** `claude-code:claude-opus-5-5` (drafting, and the fixes
  of every round). The controller made `5131b89`.

## Findings

Origin tags: **[draft]** a defect in the drafted text; **[transfer]** a
defect added while moving the drafts to the branch; **[fix]** a defect
added by an earlier fix.

GPT, round 1, resolved by round 5 (each confirmed by the verifications):

- **High, [draft]:** array caps were enforced after a child allocated.
  Resolved: every read goes through a bounded cursor limited by every
  enclosing array, and a child is checked against those limits before
  it allocates (xdr.md 5.2, point 7; 5.4, point 5).
- **High, [draft]:** no enforceable allocation bound. Resolved: a memory
  budget per message over requested bytes, kept by a ledger before each
  request and proved by the generator; fallible reservations that never
  grow; the caller enforces the message cap while buffering (5.2,
  point 9).
- **High, [draft]:** zero-width array elements broke the work bound.
  Resolved: such element types are refused, and array elements are
  decoded by a loop (5.1, points 4 and 5).
- **High, [draft]:** errors could expose secret bytes. Resolved: errors
  carry no input value, errors from a secret-bearing message carry no
  offset or length, and a secret-bearing message copies no input byte
  (5.1, point 8; 7, point 2).
- **High, [draft]:** the source rules left routes around N31. Resolved:
  every wire fact takes one of N31's two routes (README rule 14), with
  ADR 0001's isolation stated.
- **Medium, [draft]:** union dispatch and tolerance underspecified.
  Resolved: the discriminant is validated as its own type before
  dispatch, and open enumerations and string bytes are marked as IronAFS
  extensions (5.1, point 6; 5.4, points 7 and 9).
- **Medium, [draft]:** the encoder conflated array counts and byte caps.
  Resolved (5.5, point 2; P4).
- **Medium, [draft]:** several tests could not fail. Resolved: exact
  kinds and offsets, both-way golden vectors, whole-input re-encoding,
  and a safe ledger hook in place of a counting allocator (10).
- **Medium, [draft]:** G12 reused the RFC's example. Resolved: every
  vector uses IronAFS's own types and values; RFC 4506 §7 is a
  cross-check of method only.
- **Medium, [draft]:** the template made layout and caps optional for
  protocols. Resolved.

GPT, rounds 2 to 4, new majors, all resolved by round 5:

- **[fix]** inline storage and stack use were unbounded: limits on inline
  size and nesting depth, large values held out of line, and a
  small-stack test (5.2, point 10).
- **[fix]** capacity and zero-sized types escaped the budget: the budget
  counts requested bytes, never capacity (5.2, point 9).
- **[fix]** nested and zero-width out-of-line values broke the
  reservation count: the count bounds each nested reservation, and
  zero-width types are never held out of line (5.2, points 9.5 and 10.2).
- **[fix]** an out-of-line slot could be reserved before its bytes were
  present: an entry check through the bounded cursor comes first, and
  R17 tests it (5.4, point 2).
