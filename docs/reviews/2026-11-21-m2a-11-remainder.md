# Review record: `ironafs-test-support`, the exhaustive sweep and wire-message variants

## The change

Class I. Issue #44 (plan id M2a-11), the part that #83 (`4d80167`) left
open. Its first part's record is
`docs/reviews/2026-11-21-m2a-11-test-support.md`.

- `Exhaustive`: a test run on every input a generator can give, for a
  domain small enough to enumerate. It visits choice sequences depth
  first, up to a stated bound. When it passes, it prints how many inputs
  passed and the bound. A larger domain is refused at the bound, not
  sampled. A failure reports the first failing input in choice order,
  with a pasteable regression test.
- `wire`: single-bit flips of a message, integers near a known one within
  the type's limits, a type's all-zero and all-ones values, and a message
  with each field set to all zeros, then all ones.
- A regression pasted from a sweep's report of a planted length-wrap bug,
  in `tests/it/regressions.rs`.
- SplitMix64's documentation cites the reference `splitmix.c`, whose
  constants match. No published list of its outputs was found, so the
  known-answer source is recorded as UNVERIFIED. The values were checked
  by compiling and running the reference code.

  test first).
