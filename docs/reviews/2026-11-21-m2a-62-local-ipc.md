# Review record: the local IPC framework specification

## The change

Class S. Issue #62 (plan id M2a-61). **Not converged:** one required
seat passed and the other did not. The review was stopped under the stop
rule with five blockers recorded in the specification.

- `docs/specs/local-ipc.md`: the framing, handshake, envelope, numbering,
  versions, the one definition set and its digest, the error codes, and
  the order of checks on a frame, for both local IPC endpoints.
- `docs/specs/local-ipc-resources.md`: admission, the byte accounts for
  all connections and per caller, the policy budgets, ingress turns, the
  executor, deadlines and the result slot, output queues, the client's
  stream limits, and the named zeroisation places.
- `docs/specs/local-ipc-windows.md`: the Windows control pipe's instance
  pool, the one read before the caller is attested, the Windows states,
  buffer ownership across overlapped operations, the residual this
  leaves, and the Windows gate.
- `docs/specs/README.md`: the three index rows, and register rows E3 to
  E8 for the platform documents and FIPS 180-4.
- **Written by** `claude-code:claude-opus-5-5` (the first draft,
  `4187a27`) and `claude-code:claude-mythos-5-2` (every fix round, the
  split, and this record).

## Findings

Origin is "pre-existing" for the first draft's text, or the fix round
that introduced it. Each first-round finding is listed once with its
last state.

GPT, round 1:

- **Major, fixed in fix round 1** (pre-existing; contract). The
  per-caller handshake limit did not apply on Windows after the caller
  was known.
- **Major, text fixed; one part open as an owner question**
  (pre-existing; contract). The Windows pre-attestation residual claimed
  a time bound the cited documents do not give. It is now stated in
  separate parts with the completion time marked unverified. It
  contradicts ADR 0004 O23's row "None known"; that is question Q4 of
  the Windows part, for the owner, with the recommendation to amend O23.
- **Major, fixed by round 5 but for one test fixture** (pre-existing;
  missing mechanism). Admission order and the pipe pool's accounting.
  Open item M1.
- **Major, fixed by round 4** (pre-existing; missing mechanism). Decoder
  storage, connection records and operation blocks outside the
  reservation rules.
- **Major, fixed by round 5 but for one test fixture** (pre-existing;
  missing mechanism). No per-caller byte or work limit and no fair
  scheduling. Open item M2.
- **Major, open: blocker B1** (pre-existing; missing mechanism, then
  consistency). ADR 0004 C39's handoff, retryable result and deadline.
  The handoff and deadline are specified; one transition of the result
  slot is not.
- **Major, fixed in fix round 1** (pre-existing; contract). A checked
  value proved a check happened, not that the encoded secret went to
  that handle.
- **Major, fixed in fix round 1** (pre-existing; contract). The instance
  id was tested as if it authenticated the peer.
- **Major, open: blocker B2** (pre-existing; missing mechanism, then
  consistency). An adapter connection opened before registration. The
  binding state exists; its opening step and state table disagree in
  one case, and a binding handler's claim is not arbitrated.
- **Major, fixed by round 3** (pre-existing; contract). Output admission
  of a whole frame, and the order of the closing notice.
- **Major, fixed by round 4** (pre-existing; contract). Refused frames
  left their bodies unread, and the low-memory path differed.
- **Major, open: blocker B3** (pre-existing; missing mechanism, then
  consistency). The client had no stream budget. It has one; two of its
  failure paths contradict the one failure transition.
- **Major, fixed by round 3** (pre-existing; contract). The client did
  not check the chosen version or the adapter digest.
- **Major, fixed by round 4** (pre-existing; contract). Wipe coverage
  for secret buffers in both directions.
- **Minor, fixed in fix round 1** (pre-existing; consistency). The
  numbering rule forbade the zero number the format requires.
- **Minor, fixed in fix round 1** (pre-existing; consistency). Ignored
  extension tags against "no input in errors"; extension values untyped.
- **Minor, fixed by round 3** (pre-existing; contract). The digest's
  file names and discovery were not portable.
- **Minor, fixed in fix round 1** (pre-existing; other). The ADR 0005
  link did not resolve until `main` was merged.

GPT, later rounds:

- **Major, open: blocker B4** (introduced by fix round 1; contract).
  Dropping an event at saturation against ADR 0004 C16, point 6. The
  framework now reserves space for mandatory events; the append's
  eligibility and its test are still open.
- **Minor in rounds 2 and 3, major from round 4, open: blocker B5** (introduced
  by fix round 1; contract). The scope of the Windows secret gate and of
  the prefix rule.
- **Major, deferred** (introduced by fix round 2; missing mechanism). A
  teardown rule for a mandatory event past its bound contradicted the
  closing path and C16, point 6's milestones. The framework's sentences
  were withdrawn and the matter listed as Q6 of `local-ipc.md` for the
  adapter endpoint specification (ADR 0004, S1). The finding's own seat
  judged the deferral sound in round 4. No separate refutation seat
  ran, for the reason given under "The stop".
- **Minor, fixed in scoped round 3** (introduced by fix round 2;
  consistency). The index row omitted C16, point 6.

## Not verified

- No Windows behaviour was run. That a 4-byte read is enough to attest
  the caller, how long a cancelled pipe operation takes to complete, how
  Windows sizes the pipe buffers, and the daemon check of ADR 0005,
  sheet 20 are marked unverified in the specification and wait for the
  Windows gate.
- The layout ceilings and allocation counts are design numbers; no code
  exists to assert them (issue #95).
- The adapter endpoint specification is not written; what it must
  settle is Q6.
- The SHA-256 of the two-file digest vector was recomputed by one seat
  and not by the other.
