# Review record: GLM 5.4 pin calibration

Issue #48. The proposed high-effort pin moves from `glm-5.3` to
`glm-5.4` for research gathering, standard reviews and ordinary class S
and R reviews. The route is Claude Code on the Z.ai Coding Plan. The
strongest row keeps `glm-5.3` at max while its replacement is measured.
Light helpers keep `glm-5.3-flash`.

Written by `codex:gpt-6.2-sol`.

## Method

The read-only lane reviewed the six previously registered ranges against
the original answer key (SHA-256
`f82393cdd0141683bde81422b0596466ca69f1d26b9a3656e2c311b02380d2e0`).
The six ranges contain 12 planted defects, including six critical, and
one clean range. The threshold is all six critical, at least nine
planted hits, all six runs complete, zero false blockers, and at most
one false major. The lane saw the same review task with each commit range
and a terminal readback code. The controller checked the served model,
effort, completion, and readback and scored the findings against the key.
Each original-suite finding can credit one planted defect.

A separate, fresh comparison used two new IronAFS ranges with four
critical defects and a third clean range. The key was frozen before
dispatch (SHA-256
`1c3cfa0e16c42fecb63f4e487b4c850dc6dee2916618154e83c8b80466087f9a`).
The pass rule required finding all four, completing all three ranges,
zero false blockers, and at most one false major. Both models saw the
same fresh ranges at the same effort. When one report named both
locations and explained the mechanism, the controller credited each
named defect in this fresh comparison.

The fixture trees and answer keys stay private while they can still be
used. Formatting and Clippy passed for the fresh trees. One planted
clock change deliberately fails an existing test, which the controller
confirmed with isolated build output.

## Pin decision

`glm-5.4` at high passed both suites and found the previously missed
defect in the original suite. Pin it at high in the workflow, AI model
list and review-lanes skill. The live Coding Plan probe returned
the exact `glm-5.4` identifier and the wrapper passed 14 gate self-tests.
